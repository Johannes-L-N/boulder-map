# boulder-map

Outdoor bouldering map for Oslo og omegn — pins sourced from [gryttr.com](https://www.gryttr.com), rendered on Kartverket's topo basemap (with satellite + OSM alternatives).

Live: https://johannes-l-n.github.io/boulder-map/

Features:
- 2,749 boulders across 7 crags in Oslo og omegn
- Search by name with live result list
- Filter by grade band, Tørke, Utsatt, Bratthet
- "Locate me" button (HTTPS-only — works here, won't work over file://)
- Basemap switcher: Kartverket topo / Satellite / OpenStreetMap (Carto Voyager)

The data is fetched from gryttr's public GraphQL API and is for personal use.
